RIDE 隐私政策

生效日期：2026-11-20

版本：适用于 RIDE 0.0.300（versionCode 300）

政策版本 3（2026-11-15 修订：补入本机下载记录条目与 GPL 源码获取入口）

运营者：王枭鹏（个人开发者）

联系方式：rideprivacy@163.com（隐私政策：https://xpwang-stack.github.io/ride-privacy/）

一、适用范围

本政策适用于在 HarmonyOS PC/2in1 设备上安装和使用的 RIDE 应用（包名 com.harmonyr.ide）。RIDE 是一个本地运行的 R 语言集成开发环境：它在你的设备上提供一个代码编辑器、R 控制台、对象浏览器、结果表格与图形预览，并随应用内置一套 GNU R 4.6.1（ARM64）运行库与一组预装 R 包。

RIDE 不提供账号系统。 使用 RIDE 不需要注册、登录或绑定手机号；源码中未发现账号登录、云同步、统计分析或广告 SDK。

二、我们不收集的信息

基于对当前版本的源码检查，RIDE 不收集、不上传下列信息：

  • 设备标识符（IMEI、SN、OAID、ODID、MAC、芯片 ID 等）：源码中未发现任何设备标识读取调用。
  • 位置信息、通讯录、通话记录、短信、日历、相册、麦克风、相机：应用未申请任何此类权限（详见第六节）；唯一的权限是系统级 ohos.permission.INTERNET，仅用于你主动发起的 R 包源码下载。
  • 你的 R 脚本内容、数据文件内容、分析结果：不上传到任何服务器。
  • 崩溃日志与使用统计：应用未集成第三方统计或崩溃上报 SDK；诊断输出写入系统日志（见第四节），不上传。

说明：上表描述的是应用自身代码的行为。RIDE 随包分发的 R 运行库与 R 包属于第三方开源软件，其能力边界见第六节；其中 R 侧的仓库下载功能属于由你主动发起的联网行为，见第五节。

三、RIDE 在你的设备上读写什么

RIDE 只在应用自身的私有目录（HarmonyOS 应用沙箱内的 filesDir 与其子目录）内读写数据。源码中所有文件操作都以 context.filesDir 为根（例如 Console.ets 中 workspacePath = ${context.filesDir}/workspace）。

你导入的数据文件你通过系统文件选择器主动选取的数据（CSV、H5/H5AD、FASTQ 等）被复制/读取到工作区应用私有目录下的工作区供 R 会话分析

关于剪贴板：RIDE 只在你点击「复制」类按钮时写入剪贴板（例如复制对象详情、复制反馈内容）。源码中未发现读取剪贴板内容的调用。

四、数据是否离开设备

4.1 应用自身的代码路径

  • ArkTS 层（全部 .ets 文件）：没有 @ohos.net.* / @kit.NetworkKit 导入，没有 HTTP 请求、文件上传或远程上报代码。
  • 候选包 module.json 中 requestPermissions 只含一项：ohos.permission.INTERNET（系统授予，无运行时弹窗）；没有相机、麦克风、位置、通讯录、存储读写等用户授权权限。

4.2 R 侧的仓库下载能力（已启用）

RIDE 内置的 R 脚本 package_repository.R 实现了一条向 HTTPS 仓库下载 R 包源码的路径：它按你提供的仓库地址请求包索引，并按包名下载 *.tar.gz 源码包。该实现带有明确约束：仅接受 https:// 地址、不跟随重定向、单包与总量有字节上限、下载结果必须与声明的摘要一致、且只作为「数据」保存（installAuthorized=FALSE、sourceExecuted=FALSE）——下载本身不会执行任何代码。

这条路径只在你主动操作时发生：在「R 包」面板输入包名、点击「下载并检查来源」，应用才会连接你填入的 HTTPS 源码仓库（输入框默认为清华 TUNA 的 CRAN 镜像）。请求内容只有包名与仓库地址；不会附带你的脚本、数据、分析结果、设备标识或其他任何本地内容；应用不记录你请求了哪些包、也不记录请求内容，本地只保留下载所得的源码包与来源核验记录。

4.2.1 本机保留最近 20 次下载尝试记录（2026-11-14 持有人决定）

应用在沙箱内保留最近 20 次下载尝试，每条只有包名、镜像主机、时间与成功与否（失败时附一句原因），用于在 R 包面板告诉用户上次结果。不记录请求内容、响应内容、URL 路径、凭据或任何设备标识；该文件不上传，随应用数据一起删除。默认镜像为清华 TUNA 与中科大两个预设，也允许用户自行填写镜像，但只接受 HTTPS 且不含账号、查询或片段。

4.3 当前发布配置下的实测结论

0.0.279 起，发布包声明 ohos.permission.INTERNET 并启用「下载并检查来源」入口。联网行为以真机实测记录为准：validation/r-package-production-20261021/network-behaviour/result.json（文件内的 version 字段标明测得的是哪个候选，boundaries 字段说明该结论只覆盖那一台设备与那一个候选）。同一套脚本在 0.0.279（未声明权限）上测得应用内 curl::has_internet() 为 FALSE，用来证明探针确实能区分「能联网」与「不能联网」两种状态。

不使用下载入口时，RIDE 的全部功能（编辑器、控制台、对象浏览器、绘图、调试、项目、导出）都不需要网络。

五、第三方组件

1. GNU R 4.6.1 与预装 R 包：RIDE 随包分发 GNU R 4.6.1 本体和 499 条 R 包记录（顶层包与组件合并统计，去重后 499 个包名，详见 third-party-licenses.md）。这些是第三方开源软件，其许可证文本随包提供在应用内「第三方许可证」页面，可通过 resources/rawfile/licenses/r-license-notices.json 读取。

2. 原生依赖库（如 Cairo、FreeType、Fontconfig、HDF5、libcurl、Mbed TLS、zlib、bzip2、XZ、PCRE2）随 R 运行库提供，源码与许可证义务见 third-party-licenses.md。

3. 无第三方 SDK 采集：oh-package.json5（根与 entry）未引入任何商业 SDK；未发现广告、推送、统计、崩溃上报、热修复等第三方库。

七、未成年人保护

RIDE 是面向科研与数据分析用户的开发工具，不面向未成年人设计，不包含社交、支付、广告或内容分发功能。若持有人决定在应用商店中把目标受众包含未成年人，当前受众定位：不限年龄段，面向科研、教学与数据分析场景的代码工具用户；若后续调整受众，将同步更新分级与本政策。
